Accessibility statement

Publisher Rigour Consulting Pty Ltd Location Perth, Western Australia Effective date 22/11/2026 Feedback contact rigour.consulting@gmail.com

Rigour Consulting Pty Ltd is committed to ensuring that the Consotelo software application and this public website are accessible to people of all abilities, including users relying on assistive technology.

Our accessibility standard

We aim to conform to the Web Content Accessibility Guidelines (WCAG) version 2.2 at Level AA. These guidelines define best practices for making digital content perceivable, operable, understandable, and robust for people with disabilities, including vision, motor, cognitive, and hearing impairments.

Accessibility features of this website

This public website incorporates the following accessibility features:

  • Semantic HTML markup Clear document structure using landmark elements such as header, navigation, main, article, section, and footer to facilitate screen reader navigation.
  • Logical heading hierarchy A structured heading order from h1 through h3 without skipped levels or empty heading elements.
  • Keyboard navigation All interactive elements, including links and buttons, are reachable and operable using a keyboard alone.
  • Visible focus indicator A distinct, high-contrast outline appears around focused elements during keyboard navigation.
  • Skip navigation link A dedicated skip link at the top of every page allows keyboard and screen reader users to bypass primary navigation and jump directly to the main content.
  • Colour contrast Text and interactive components are designed to meet or exceed WCAG 2.2 Level AA contrast requirements. Body copy in dark graphite on porcelain background achieves a contrast ratio greater than 12 to 1, far exceeding the 4.5 to 1 minimum.
  • Responsive zoom and scaling Content flows responsively from narrow mobile screens (360 pixels wide) up to large desktop monitors. Pages remain fully readable when zoomed up to 200 percent and 400 percent without horizontal scrolling.
  • Motion sensitivity Smooth scrolling transitions respect the reduced-motion preferences configured in your operating system or browser.

Accessibility across our software applications

Within the Consotelo Android and Windows desktop applications, we implement native accessibility features including platform screen reader labels, scalable text sizing that honours operating system accessibility settings, and tactile feedback where appropriate.

Known limitations and ongoing improvements

While we test our pages using automated checkers, screen readers, and keyboard navigation, we recognise that accessibility is an ongoing engineering commitment. Some printable A4 legal agreement documents are rendered as formatted PDF documents; for users requiring plain text, agreements can be reviewed directly in structured HTML view prior to signature.
